# CHANGELOG — AranduIA

Todos los cambios notables en este proyecto serán documentados en este archivo.
El formato se basa en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/) y adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [0.1.0] - 2026-10-01

### Agregado
* **Lanzamiento Fundacional de AranduIA:**
  * Arquitectura completa documentada en 14 capítulos técnicos en `docs/`.
  * Manual de referencia para Asistentes de Inteligencia Artificial (`AI_CONTEXT.md`).
  * Propósito, alcance formal y filosofía en `PROJECT_BRIEF.md`.
  * Guías comunitarias: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` y `.github/` templates.
* **Módulo Núcleo (Backend FastAPI):**
  * Motor de Tutoría Socrática con soporte neurodivergente (Modo TEA / Sensorial / Pictogramas).
  * Motor Copiloto Docente para generación de planes de lección y rúbricas alineadas al MEC.
  * Motor lingüístico bilingüe (Español / Guaraní Jopara).
  * Módulo de minimización de datos y privacidad bajo la Ley N° 7593/2025 de Paraguay.
  * Endpoints REST para tutor, docente, sincronización offline y simulación de WhatsApp Gateway.
* **Frontend Web & PWA:**
  * Portal web interactivo y accesible (WCAG AAA) para docentes y estudiantes.
  * Selector de Modo TEA (modo sensorial calmado y pictogramas visuales).
  * Soporte offline mediante Service Worker y almacenamiento local.
* **Infraestructura:**
  * `Dockerfile` y `docker-compose.yml` listos para despliegue local o servidores comunitarios.
  * Suite de tests automatizados con `pytest`.
